HACK//LAB 7.0 DEEP — 長期学習カリキュラム
============================================

■ 内容
- 12ルート、300レッスン（各ルート25レッスン）
- 662用語の用語集
- 6段階で学ぶ：教科書 → 実例 → ガイド付き実習 → 自力チャレンジ → 記述式理解チェック → 振り返り
- 各段階は別のHTMLページ・別URLで開きます。必要ならページ間を移動できます。
- 目安学習時間はカリキュラム全体で約276時間。1回で終わる教材ではなく、読む・試す・説明する・記録する前提です。
- Google Gemini APIによるクラウド家庭教師。ローカルAIは使いません。

■ Windowsで起動
1. ZIPを展開し、フォルダーを開きます。
2. .env.example を .env にコピーします。
3. .env の GEMINI_API_KEY に、Google AI Studioで取得したAPIキーを設定します。
4. start_windows.bat をダブルクリックします。起動用の黒い画面が残ります。
5. ブラウザで http://127.0.0.1:8765/ を開きます。
6. 起動用の黒い画面は起動中そのままにします。エラーが起きても画面は閉じず、内容を表示します。終了時は Ctrl+C。
- 「Python 3 が見つからない」と出たら、Python 3.10 以降をインストールし、インストーラーの PATH 追加項目を有効にしてから、バッチをもう一度開きます。
- ポート 8765 が使用中なら、別の HACK//LAB サーバーを閉じるか、表示されたエラーを確認します。

■ .env の例
GEMINI_API_KEY=取得したキー
GEMINI_MODEL=gemini-3.5-flash-lite
HACKLAB_PORT=8765

■ 学習方法
- 初めてなら、ホームのルート01から始めます。
- 教科書・実例・実習・課題・記述式テスト・振り返りが別ページになっています。
- 1ページを終えたら「このページを読了して次へ」を押すと進捗に記録されます。
- 理解チェックでは2問の記述に回答し、模範解答と採点基準を比較します。
- 各ページからGeminiに現在のレッスンを添えて質問できます。
- 進捗・ノートはブラウザ内に保存されます。進捗ページからJSONバックアップを作成してください。

■ Linuxコマンドについて
このWebアプリは、教材として示したコマンドをホストPC上で自動実行しません。LinuxコマンドはUbuntu/WSLや仮想マシンなど、自分の練習環境で確認してください。Windows PowerShellのコマンドとは別です。管理者権限・削除・ネットワーク変更などは、対象と副作用を理解してから実行してください。

■ セキュリティ演習
所有・管理している端末、ローカルラボ、または明示的に許可された環境だけを対象にします。第三者システムへの無断アクセス、認証回避、情報取得は行わないでください。難しい演習は架空ログ、設計図、模擬データを用いても学べます。

■ Gemini / 費用・秘密情報
- APIキーはブラウザに置かず、サーバー側の .env に設定します。
- APIキー、パスワード、秘密鍵、個人情報をAI家庭教師へ送らないでください。
- アプリ内には1日あたりの送信回数制限がありますが、これはGoogle側の課金・無料枠を保証するものではありません。Google AI Studio側の対象プロジェクトの無料枠・課金リンク状態を確認してください。有料課金を利用しないなら、請求先アカウントをリンクせず無料枠内で使用します。
- 無料枠が変更される場合があります。上限エラー時には自動で有料モデルへ切り替えません。

■ 保管ファイル
- index.html, roadmap.html, lesson.html, example.html, guided-practice.html, challenge.html, quiz.html, review.html: ページ
- data/course.js: ブラウザ用カリキュラム
- data/course.json: カリキュラム編集用データ
- server.py: ローカルWebサーバーとGemini API中継
- .env.example: 環境変数のひな形
